# Fieldnotes

An editorial design journal built with Astro. Pages and articles are statically
generated by default; the Vercel adapter is ready for routes that need server
rendering later.

## Requirements

- Node.js 22.12 or newer and npm
- [uv](https://docs.astral.sh/uv/) for the optional Python tooling environment

## Getting started

```sh
npm install
npm run dev
```

The local site is available at `http://localhost:4321`.

## Content

Add Markdown posts to `src/content/posts/`. The collection schema in
`src/content.config.ts` validates each post's title, description, publication
date, category, tags, and draft status. Posts marked `draft: true` are excluded
from the public listing and generated routes.

## Python tooling

Python is not part of the deployed site runtime. The root `pyproject.toml` uses
uv to manage a separate environment for optional content, image, or migration
utilities:

```sh
uv sync
uv run ruff check .
```

Add Python tooling dependencies with `uv add` or `uv add --dev`; commit the
updated `pyproject.toml` and `uv.lock`.

## Build and deploy

```sh
npm run build
npm run preview
```

Connect the repository to Vercel and use the default Astro build command.
Static routes remain prerendered. When a route needs server-side rendering,
opt it out of prerendering with `export const prerender = false`; the Vercel
adapter will serve it dynamically. To host elsewhere, remove the Vercel adapter
from `astro.config.mjs` and choose that host's adapter only if server rendering
is needed; a static build can also be hosted from `dist/`.

## Project structure

```text
src/
├── content/
│   └── posts/       # Markdown articles
├── layouts/         # Shared page shell
└── pages/           # File-based routes
```
